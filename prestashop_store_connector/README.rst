Prestashop Connector
====================

Connects Odoo 20 with PrestaShop stores to import and export products, contacts, and sales orders seamlessly.

Installation
------------

* Install the required Python dependency: ``pip install prestapyt``.
* Install the ``prestashop_store_connector`` module in Odoo 20.

Usage
-----

1. Open your PrestaShop admin panel under **Advanced Parameters > Webservice**, enable the Webservice, and generate an API key with the required resource permissions.
2. In Odoo 20, open **Prestashop Connector > Instances** and create an instance with your API URL and API key.
3. Click **Connect**, then import or export products, contacts, and orders from the respective instance tabs.
4. Review synchronized records under **Prestashop Connector > Orders**, **Contacts**, and **Products**.
