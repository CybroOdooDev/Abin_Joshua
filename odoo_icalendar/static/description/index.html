Answers Before You Install

Q
Does this module support Odoo 20 Community and Enterprise Editions?
A
Yes, it is fully certified for Odoo 20 Community Edition and also operates flawlessly on Odoo 20 Enterprise, Odoo.sh, On-Premise, and Odoo Online without requiring any external paid subscription.
 
Q
How do I generate and email an ICS file to meeting attendees?
A
Open any event in the Calendar module and click the 'Send ICS' button. The system generates the RFC 5545 .ics file and automatically emails it as an attachment to all attendees with valid email addresses.
 
Q
Can I send multiple calendar meetings in a single email?
A
Yes. From the Calendar list view, select multiple events and choose 'Send ICS File' from the 'Action' dropdown menu. The module consolidates all relevant events into an 'All_Events.ics' attachment tailored for each attendee.
