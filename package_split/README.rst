Categorize & Pack Products
==========================

This module allows users to split product packages based on the package category assigned to each product.

Key Features
------------

* Assign custom package categories to products.
* Automatically split products into different packages by category during the Put in Pack operation.
* Append package category name to generated package identifiers.
* Manage and group packaging operations efficiently in inventory transfers.

Installation
------------
No external dependencies.

Configuration
-------------
Enable Packages under Inventory Settings, and configure package categories as needed.
